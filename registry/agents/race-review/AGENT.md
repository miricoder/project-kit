# Race review

Runs three skills in order on one provider:

1. `screenshot-reader` — splits out of the result screenshots; the athlete confirms them
   before anything is saved.
2. `race-analyzer` — time to gain per segment against the target, compared with earlier
   races.
3. `pace-planner` — run targets per machine and the progression to the next race.
