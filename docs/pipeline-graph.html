Why the pipeline stopped at build

  1. It did run. pk state next and pk gate phase build both pass; the state says the next step is run /build.
  2. Nothing answers /build. The pipeline maps each phase to a skill of the same name. Skills exist for ideate → initiate (plus /remediate and /pipeline). /build, /devops, /test, /security and /launch are declared phases with no skill (red dashed nodes). The pipeline skill itself says “build onward are declared in state and have no skill yet”.
  3. So yolo mode reaches a dead end at build. Slices are built by hand until /build ships, as /initiate instructs, and nothing reaches your phone until slice 4 is built and /launch (also missing) ships it.
  4. In this cloud session the plugin did not load, so even the existing skills could not be called by name; the same commands were run from bin/pk on main.
