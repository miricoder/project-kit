Install

claude plugin marketplace add miricoder/project-kit
claude plugin install project-kit

Then /reload-plugins, or start a new session. Verify with claude plugin details project-kit; update later with claude plugin update project-kit.

Requires Claude Code 2.x or newer — plugin support. Check claude --version; upgrade with npm i -g @anthropic-ai/claude-code@latest.

Using it

/ideate I want an app that tracks my houseplants
/pipeline                 # where are we, what runs next
/pipeline mode yolo       # manual | auto | yolo
/pipeline run --to design
ModeBehaviourStops

Two layers of autonomy

yolo removes Project Kit's checkpoints. It cannot remove Claude Code's own tool-permission prompts — those are harness-level and no plugin can suppress them. For a genuinely unattended run, allowlist them too:

// ~/.claude/settings.json
{
  "permissions": {
    "allow": ["Bash(python3:*)", "Bash(git:*)", "Bash(gh:*)", "Edit", "Write"]
  }
}

/pipeline mode yolo reports whether this is configured, so the mode never looks hands-off while silently waiting on a prompt.

Budget

Every project carries budget.max_usd in its pipeline.json. yolo adds no confirmation stops but still halts when spend passes the ceiling — what that rules out is an unattended REJECT → re-judge → REJECT loop burning credit with nobody watching.

The judge panel

The judge gate needs three verdicts from three different model families. Two rules are enforced in code, not left to judgement:

  1. No family may hold two seats. Two judges from one family share priors, producing a ruling that looks independent and is not.
  2. The authoring family is excluded. Claude writes the plan, so Anthropic cannot judge it.
TransportWhen
api_keyA real API key exists. Fully automated
cliA subscription-backed CLI — e.g. npm i -g @openai/codex reuses an existing ChatGPT login, no API key and no extra cost
pasteNeither. The brief is rendered for you to paste, and the returned JSON is validated before being accepted

A ChatGPT subscription is not an OpenAI API key. Using api_key for that seat means paying for API usage separately; cli avoids it.
